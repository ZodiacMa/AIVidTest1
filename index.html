跨域与免费托管指南（展开查看）

根据阿里云 API 网关跨域说明，服务端需在响应中显式返回 Access-Control-Allow-Origin 等字段才能被浏览器访问。百炼公共域名未开放任意来源，因此必须通过自建代理。

  1. 本地代理：可使用 Node/Express、Nginx 或 curl --proxy 等方式，将 /dashscope 路径转发到 https://dashscope-intl.aliyuncs.com，并设置允许跨域的响应头。
  2. Cloudflare Workers（免费）：在控制台创建 Worker，粘贴仓库内 proxy-worker.js 脚本并部署，即可获得 https://<子域>.workers.dev/dashscope 作为代理地址。
  3. Vercel Edge Functions（免费额度）：在 Vercel 新建项目，参考 README 中的 TypeScript 代理示例部署到 /api/dashscope。
  4. 若需企业级稳定性，可在公司内部网关或函数计算部署，确保响应头允许来源 * 或页面访问域。

② Supabase（如需托管素材）
默认 anon key 受行级安全（RLS）限制，如遇 403 需在 Storage -> Policies 中为目标桶放行 INSERT/SELECT，或改用 Service Role Key。 页面已默认填入 Supabase 项目与目标桶名称，如需更换请同步更新。
Supabase 行级安全排查步骤
  1. 登录 Supabase 控制台，进入 Storage > Buckets，选择目标桶。
  2. 切换到 Policies 标签页，新建策略：auth.role() = 'anon' 且 request.method() = 'POST' 允许 INSERT；同理再建一条允许 SELECT。
  3. 若暂不希望开放匿名写入，可改用 Project Settings > API 中的 service_role Key，并确保该 Key 仅在可信环境中使用。
  4. 完成策略调整后，点击上方“检测 Supabase 凭证”验证权限是否已生效。
